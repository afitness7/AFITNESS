# A FITNESS — Website Starter

This is a responsive, single-page website starter for A FITNESS.

## Run it
1. Extract `A_FITNESS_Website.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No installation or paid account is required for local preview.

## Included and working
- Responsive dark green + black homepage
- A FITNESS logo and favicon included
- Basic SEO title, description, social preview metadata and index/follow directive
- Navigation to Workout, Nutrition, Calculators, Progress and Premium sections
- Hindi/English text toggle for the main website content
- BMI calculator
- Daily calorie estimate (Mifflin–St Jeor)
- Water tracker saved in this browser using localStorage
- Weight entries saved in this browser using localStorage

## Important limitations of this starter
This is Phase 1: a front-end website starter. It does NOT yet include secure user accounts, cloud database sync, admin authentication, video uploads, paid subscriptions/payments, coach chat, or real premium access control. Premium is marked Coming Soon so the site does not pretend those systems are active. Do not collect real user credentials or payment details in this version.

## Before publishing
The logo and favicon files must stay in the same published folder as `index.html`. Keep all three files together: `index.html`, `a-fitness-icon.png`, and `a-fitness-logo.png`.

## Free publishing
You can publish the static site using a free static hosting provider such as GitHub Pages or Cloudflare Pages. Upload the extracted files and follow that provider's current deployment instructions. A free provider subdomain is normally used; a custom domain may cost money.

## Next development phase
Add a real backend/authentication provider, role-based admin access and database security rules before enabling user accounts, cloud progress sync, admin tools or subscriptions. Never place private API keys in browser JavaScript.
